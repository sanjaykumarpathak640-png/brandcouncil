# Roadmap

**Next (1-3 months)**: OCR for scanned PDFs and images without AI; layout-aware image checks (text over busy areas); multi-brand workspaces; email/Slack notifications on submit and verdict; persistent database (Postgres) and real user accounts with SSO.
**Then (3-6 months)**: publishing integrations (Buffer, WordPress, LinkedIn) so approved content is scheduled from BrandCouncil; a larger labelled benchmark built from real reviewer decisions, with a drift alert when accuracy drops; per-channel rules (a tweet vs a newsletter); multi-language guidelines.
**Later**: learning which flags each brand's reviewers accept, to rank flags by likely usefulness (never to auto-approve); brand-book version history and rule diffs; a public API for CMS plug-ins; an accessibility audit export for compliance teams.
